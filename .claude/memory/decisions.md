# Decisions

- **2026-09** — Single-tenant scope: the whole system serves exactly one education center. No multi-tenant/Center model, no tenant isolation logic.
- **2026-09** — Account model is parent-only: one login account belongs to a parent, who holds one or more `StudentProfile` children. There is no separate student login, ever.
- **2026-09** — Parent role is Mobile-only per the latest spec (Web + Mobile for manager/teacher, Mobile for parent) — don't build a parent web UI unless this changes.
- **2026-09** — Shadcn preset: **Maia** (soft, rounded, generous spacing) — chosen for a friendly, non-clinical feel for parents.
- **2026-09** — Route groups by role: `(public)`, `(auth)`, `(manager)`, `(teacher)`, `(parent)` — each with its own layout.
- **2026-09** — State management: TanStack Query for server state, `nuqs` for URL state, plain React state for local UI. No Redux/Zustand.
- **2026-09-30 (role refactor)** — Web has 5 roles: `admin`, `center_manager`, `curriculum_designer`, `staff`, `teacher` (+ `parent` mobile-only). The first four share ONE back-office tree `/manager/*` (route group `(manager)`, name kept for URL stability — it is not the `center_manager` role); screens per role live only in `src/constants/role-access.ts`, enforced by `proxy.ts`, sidebar filter and hidden cross-role buttons. No finer permissions inside a role (only `ACCOUNT_MANAGE_TARGETS`).
- **2026-09-30 (registration)** — Parent account + child profile are created by the parent on mobile first; staff looks up by Gmail → picks child → grade → subject → class (fixed schedule) → offline payment. **Activation link/code, `ActivationLink`, `pending_link` are removed entirely.** Center manager cannot create parents on web (only edit/lock/soft-delete).
- **2026-09-30 (curriculum)** — Monthly test is NOT stored on `Lesson`; it is auto-inserted as the last session of each calendar month when sessions are generated (`ClassSession.kind = monthly_test`). Curriculum is editable by admin, center manager and curriculum designer.
- **2026-09-30 (teacher)** — Teaching schedule is fixed by the center (teachers give no availability, cannot decline). Work-credit = 1 per session the teacher marked attendance for (substitute gets it, not the original); no pay rate yet. Sudden absence: teacher reports → center manager assigns a substitute or cancels the session (class goes to the make-up queue).
- **2026-09-30 (UI reuse)** — Refactor role = gắn role vào UI có sẵn, KHÔNG tạo trang mới. Công giáo viên là tab "Công" trong Chi tiết giáo viên (`/manager/teachers/[id]?tab=work-credits`, quản lý/admin ghi nhận công) và một khối ở cuối trang Điểm danh của giáo viên; báo nghỉ là nút trong drawer lịch dạy, xử lý ở trang Dạy thay, buổi bị hủy chờ học bù nằm ở trang Học bù. Wizard đăng ký dùng `ParentPicker`/`EntityPicker` có sẵn.
- **2026-09-12** — Brand primary color: blue `#2563EB` (not green `#16A34A`) — the design doc allowed either; blue chosen by the user when the shared theme file was built. See [[progress]] for the full theme token list.
