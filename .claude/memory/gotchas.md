# Gotchas

- **Storage/avatar (2026-10-27)**: Multer báo LIMIT_FILE_SIZE ngay tại giới hạn; parser avatar dùng MAX+1 byte còn validator giữ <=5 MiB. RHF native file input có thể khởi tạo FileList rỗng: chỉ File thật mới là lựa chọn chưa lưu. Role-preflight BFF có thể xoay token trước validation nên cả response lỗi phải giữ cookie mới. Avatar dùng Base UI `onLoadingStatusChange`, không chỉ DOM onError; URL chỉ ở Query cache, không lưu vào profile. BE preview chỉ inline ảnh, PDF vẫn attachment; signed preview 300s, download 60s, avatar 900s. Browser Strict Mode có thể hủy rồi gửi lại query mount: phân biệt request bị hủy với số lần phục hồi ảnh hoàn tất trong test.

- **Error presentation (2026-10-16)**: `ZodError.message` là chuỗi mảng JSON, không dùng trực tiếp làm nội dung UI. `apiErrorMessage` và các shared feedback/form/boundary dùng `userFacingMessage` để diễn giải issues hoặc metadata lỗi có giới hạn, giữ thông báo nghiệp vụ tiếng Việt và fallback theo ngữ cảnh. Không render error.details/requestId, lastError của provider hoặc lỗi worker trực tiếp. Snapshot audit cũ có thể là chuỗi JSON: chỉ giải mã before/after gốc, không tự parse nội dung bài học/ghi chú. Local test transpile TypeScript phải đặt target ES2017+ để Set spread hoạt động đúng.

- **Monthly dashboard (2026-10-14)**: ngày đầu tháng UTC+7 nằm ở ngày cuối tháng trước trong UTC; tăng tháng bằng setUTCMonth trực tiếp sẽ bỏ sót tháng 28/30/31 ngày. Analytics phải tăng theo lịch UTC+7 rồi dịch về UTC, đã có test qua giao năm. Noto Serif được bundle qua next/font để tiêu đề tiếng Việt không tách glyph khi font hệ thống thiếu ký tự. Theme warm được bật theo pathname dashboard và body:has cho portal, giữ snapshot hydration cố định.

- **Dashboard/menu/Kanban (2026-10-14)**: Analytics dùng khoảng ISO tối đa 366 ngày và bucket UTC+7; revenue theo kỳ, hồ sơ/tài khoản/đăng ký là tổng hiện tại. Export XLSX qua BFF giữ bytes/MIME và xử lý lỗi JSON. Sidebar dùng đường dẫn khớp dài nhất để tránh hai mục active; đọc trạng thái localStorage qua useSyncExternalStore với server snapshot cố định để không mismatch hydration. Button size icon chỉ render leftIcon/rightIcon, nên caller phải truyền icon và aria-label; dialog/sheet mới dùng nút đóng rõ thay default. Board cuộn ngang trong vùng riêng; mutation vẫn đi qua detail với preview/revision/idempotency.

- **Curriculum review/import (2026-10-14)**: `PENDING_REVIEW` có hai bước theo `technicalReviewedAt`; chỉ teacher được chỉ định duyệt, Manager không xác nhận trước. Teacher trả nháp sẽ mất quyền đọc detail nên redirect queue. Không sửa lesson/phiên bản đang dùng qua API legacy. Assignment import dùng endpoint Teacher riêng (file+classId), không dùng upload bài nộp Parent. Preview Word/PDF cần AI cấu hình; CSV không cần AI. Buổi TEST phải chưa kết thúc và thuộc đúng giáo viên/lớp; kiểm tra lại khi publish. Pending cũ thiếu reviewer cần Manager trả nháp để gửi lại.

- **Hydration/body (2026-10-14)**: thuộc tính `__processed_<uuid>__` không đến từ source FE, phù hợp với tiện ích trình duyệt sửa DOM trước hydration. Chỉ đặt `suppressHydrationWarning` tại `body` cho trường hợp này; không áp dụng rộng cho các component con. Audit snapshots phải render thành trường/danh sách dễ đọc, không in JSON trên UI; requestId vẫn giữ trong ApiError nhưng không hiển thị trên giao diện.

- **Web workflow API (2026-10-10)**: single absence cần participant/roster đã được Teacher chuẩn bị; Staff không được tự POST roster. Hủy makeup không xóa participant unique key của BE, nên cùng enrollment không đặt lại được cùng target session; lọc các target từng đặt và chọn buổi khác. Parent-only upload/submission không mở trên BFF Web.
- **Report/AI/email**: BFF phải giữ bytes và content-type/disposition khi tải PDF/XLSX; lỗi JSON có thể đến dưới dạng blob. AI proposal không tạo/công bố GradeReview; vẫn cần Teacher lưu, approve rồi publish. Lưu announcement chưa gửi email; hiển thị kết quả từng recipient từ lệnh send, không dùng success chung cho SMTP.
- **MySQL/Chromium test local**: chỉ migrate database biệt lập và drop sau test. Nest test phải chạy với cwd của BE vì PDF tìm `assets/fonts` từ cwd. Base UI Checkbox có input ẩn cùng label; chọn `getByRole("checkbox", { name })` khi kiểm thử tương tác.

- **Academic API (2026-10-09)**: scheduled-sessions list không có revision; phải GET detail trước đổi/hủy. Mutation session trả scalar, nên invalidate/refetch detail thay vì ghi response vào cache detail. Teacher không có lớp có thể nhận [] dù curriculum query dùng paginated=true.
- **CSV Academic**: diagnostics của preview dùng code/field, không có message. Commit phải bỏ diagnostics và giữ nguyên chuỗi preview. Preview file tối đa 5 MiB nhưng JSON BE giới hạn 1 MiB; FE kiểm tra byte UTF-8 trước commit. Luôn retry bằng body/key đã lưu, kể cả preview đã hết hạn sau request có kết quả chưa xác định.
- **Base UI Select trong Dialog**: Positioner fixed tạo stacking context, z-index chỉ trên Popup không đủ. `globals.css` đặt layer cho positioner của select-portal để danh sách hiện trên dialog; không ép force-click trong kiểm thử để bỏ qua lỗi tương tác.

- **npm project naming**: `create-next-app <Name>` fails if the name has capital letters (npm naming restriction). Scaffold into a lowercase temp folder, then move contents into the real (capitalized) repo folder.
- **PowerShell + git folders**: moving a freshly-scaffolded Next.js folder (which has its own `.git`) into a repo folder that already has `.git` fails on `Move-Item` for the `.git` directory specifically — everything else moves fine. Delete the leftover temp folder's `.git` remnants afterward and verify with `git status` in the destination.
- **SafeAreaView (mobile)**: must import from `react-native-safe-area-context`, not from `react-native` — the built-in one doesn't handle notches correctly.
- **FlatList (mobile)**: parent container needs `flex: 1` or scrolling silently breaks.
