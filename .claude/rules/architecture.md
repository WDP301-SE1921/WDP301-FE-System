# Architecture

## Route groups (by role)
- `(public)` — landing/about page, no auth required.
- `(auth)` — login, register (parent self-registers via activation link/code sent after payment confirmation).
- `(manager)` — center manager: students, teachers, classes, payments. Web only.
- `(teacher)` — schedule, attendance, grading, reports. Web + Mobile.
- `(parent)` — dashboard, per-child schedule/grades. Mobile only per current spec. One account can hold multiple children.

## Key folders
- `components/ui` — generated by the Shadcn CLI, don't hand-edit.
- `components/shared` — cross-role components (Header, ChildSwitcher, Sidebar). See `shared-component-architecture.md`.
- `features/<domain>` — colocate domain logic + UI instead of growing `components/` unbounded.
- `lib/validators` — Zod schemas, shared between forms and API calls.
- `hooks/` — custom hooks + TanStack Query hooks.
- `providers/` — `QueryClientProvider`, theme provider; wraps the root layout.

## Auth model
One login account = one parent, who can hold multiple child profiles (`StudentProfile`). No separate student login — a child submits homework/views grades through the parent's session.

## State management
- Server state: TanStack Query.
- URL state (filters, pagination, tabs): `nuqs`.
- Local UI state: React `useState`/`useReducer` — no global client store.
