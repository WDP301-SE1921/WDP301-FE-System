# Tech Stack

- Next.js (App Router) + TypeScript
- Shadcn UI (Maia preset) + Tailwind CSS
- React Hook Form + Zod
- TanStack Query + Axios
- nuqs (URL state), date-fns

## Commands
- Install: `npm install`
- Dev: `npm run dev`
- Build: `npm run build`
- Lint: `npm run lint`
- Add a Shadcn component: `npx shadcn@latest add <component>`
